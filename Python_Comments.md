# Python Comments

## What are Comments in Python?

Comments are used to explain the code. They help us understand the code easily.

Python ignores comments during program execution.

We use the `#` symbol to write a single-line comment in Python.

## Example

```python
# This is a comment
print("Hello World")
```

**Output:**

```text
Hello World
```

## Types of Comments

### 1. Single-Line Comment

A single-line comment starts with the `#` symbol.

```python
# Print a message
print("Hello")
```

### 2. Multi-Line Comments

We can write multiple comment lines by using the `#` symbol at the beginning of each line.

```python
# This is the first line
# This is the second line
print("Hello World")
```

## Advantages of Comments

1. Comments make code easy to understand.
2. Comments explain the purpose of the code.
3. Comments improve code readability.
