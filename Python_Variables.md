# Python Variables

## What are Variables in Python?

Variables in Python are used to store data.

A variable is like a container that holds a value.

We can store different types of data in variables, such as names, numbers, and decimal values.

## Example

```python
name = "Rishabh"
age = 22
height = 5.8

print(name)
print(age)
print(height)
```

**Output:**

```text
Rishabh
22
5.8
```

## Explanation

- `name` is a variable.
- `"Rishabh"` is a string value.
- `age` is a variable.
- `22` is an integer value.
- `height` is a variable.
- `5.8` is a float value.
- `print()` is used to display values.

## Rules for Naming Variables

1. A variable name must start with a letter or an underscore.
2. A variable name cannot start with a number.
3. Variable names can contain letters, numbers, and underscores.
4. Variable names are case-sensitive.
5. We cannot use Python keywords as variable names.

## Examples of Valid Variables

```python
name = "Rishabh"
age = 22
user_name = "Rahul"
_marks = 90
```

## Examples of Invalid Variables

```python
# 2name = "Rishabh"
# user-name = "Rahul"
```

These are invalid because variable names cannot start with a number or contain a hyphen.

## Changing Variable Values

We can change the value of a variable whenever needed.

```python
age = 22
age = 23

print(age)
```

**Output:**

```text
23
```

## Advantages of Variables

1. Variables store data.
2. Variables make code easier to understand.
3. Variables help us reuse data.
4. Variables make programs easier to manage.
